# 🌐 Language Translator

A simple and user-friendly Language Translator web application that allows users to translate text between multiple languages instantly. The application provides a clean interface where users can enter text, select source and target languages, and receive accurate translations in real time.

## ✨ Features
- Translate text between multiple languages
- Clean and responsive user interface
- Easy language selection
- Fast and accurate translations
- User-friendly design

## 🛠️ Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Translation API / Translation Library
